Praso Design System

Tokens e componentes extraídos dos prints do app (iPhone, 393×852pt). Tudo é HTML + CSS + JS puro: inclua tokens.css, components.css, data/catalog.js, praso.js e screens.js, e chame Praso.ui.*. Os componentes abaixo são interativos.

Cores

A paleta do app segue a escala do Tailwind (gray / green / red) + o azul da marca.

Tipografia

Fonte do sistema (SF Pro no iOS; Inter como fallback). O app usa tipografia compacta — tamanhos calibrados medindo a largura dos textos nos prints.

Ícones

Praso.icon('nome', { size, sw }) — traço 1.6–1.8, cantos arredondados. Variantes -fill são usadas na aba ativa.
